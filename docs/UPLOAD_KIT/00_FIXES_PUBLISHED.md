## 4. The same episode is on the channel twice (owner decides)

Two versions of the same topic split views and can look like repeated content. Suggestion: keep the newer version public and set the older one to **Unlisted** (Studio → Visibility). Unlisted keeps its views and links; nothing is deleted.
