Let me draw Theo's problem. Output equals the number of workers, times what each worker produces. If the number of workers starts falling, and in Europe it's about to, there's just a single way to keep growing. Each worker has to produce more. So Theo asks the obvious question. What if technology let his factory make far more with far fewer people? Then a shrinking workforce stops being a death sentence. And a different question starts to matter.
