# Propriedade intelectual — Clara e as Patinhas

Estrutura pedida no Aditivo 01, §33. Cada pasta tem um README explicando o conteúdo.

- `trademarks/` — Marcas: nomes provisórios (Clara e as Patinhas, Clara & Paws, Clara y sus Patitas, Clara Kids Studios), pesquisas de anterioridade e a preparação para o INPI (`PREPARACAO_MARCA.
- `character-bible/` — Bíblia dos cinco personagens (`BIBLIA_PERSONAGENS.
- `music-rights/` — Identidade musical, perfil de voz travado (`VOICE_PROFILE.
- `visual-assets/` — Índice dos ativos visuais registráveis: logos, paleta, model sheets, imagem oficial da turma, miniaturas.
- `licensing/` — Relatório de licenciamento (`RELATORIO_LICENCIAMENTO.
- `authorship/` — Registro de autoria (`CONTRIBUICOES_HUMANAS.
- `originality-reports/` — Pesquisas de originalidade (`RELATORIO_ORIGINALIDADE.
- `contracts/` — Contratos e termos (cessão de direitos, prestadores, distribuidoras).
- `source-files/` — Índice dos arquivos-fonte (scripts de geração, planos de composição, .
- `registration-ready/` — Pacotes prontos para registro, montados só quando o proprietário decidir registrar: especificação de marca por classe, imagens do logotipo, memorial descritivo dos personagens.

**Aviso:** nada aqui é parecer jurídico. Licença de uso comercial não é o mesmo que titularidade exclusiva; obras geradas só por IA têm proteção autoral incerta.
